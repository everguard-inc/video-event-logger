# Video Event Logger 0.3.10

Дата релізу: 2026-11-06. Цільовий пакет: Ubuntu 20.04 amd64. Фонова черга завантажень.

- Послідовна черга HTTPS/S3-посилань із паралельними з’єднаннями для активного файлу, фоновим завантаженням і розпакуванням ZIP / TAR / TAR.GZ.
- Незалежний від діалогу менеджер черги, індикатор у рядку стану, приховування/повторне відкриття Downloads, скасування й повторні спроби. Вихід підтверджує скасування всієї черги та чекає очищення без блокування GUI.
- Готові відео відкриваються або додаються до Playlist лише явно. Поточна розмітка не перемикається. Існуючі файли зберігаються; повторювані назви отримують номер.
- Регресійні тести окремими процесами перевіряють реальні HTTP-завантаження, архіви, доступність GUI, редагування анотацій, повторне створення діалогу та вихід.

# Video Event Logger 0.3.9

Дата: 2026-10-29. Цільовий пакет: Ubuntu 20.04 amd64, із перевіркою встановлення на Ubuntu 24.04.

- Виправлено помилку встановлення `libssl.so.1.1: cannot open shared object file`: Python тепер збирається з тим самим OpenSSL 3, який входить до пакета для Qt. Системний OpenSSL 1.1 не потрібен.
- Перевірка збірки відхиляє залежності пакета від OpenSSL 1.1 та перевіряє, що Python `_ssl` і `_hashlib` використовують вкладені бібліотеки OpenSSL 3.
- Smoke-test перевіряє Python TLS і Qt TLS окремо.
- Додано обов’язкову перевірку встановлення архіву й запуску встановленого launcher у чистому контейнері Ubuntu 24.04 без OpenSSL 1.1 та інструментів збірки.
- Користувацькі функції й схема JSON залишаються такими, як у 0.3.8.

# Video Event Logger 0.3.8

Дата: 2026-10-28. Цільовий пакет: Ubuntu 20.04 amd64.

## Зміни

- Playlist із відкриттям кількох відео або папки, показом/приховуванням та панеллю у fullscreen при наведенні на лівий край.
- Events Bar: відображення інтервалів, редагування меж перетягуванням або точним вводом, Play/Edit/Delete, масштабування колесом від позиції курсора, зміна висоти та окрема видимість у fullscreen.
- File → Recent для відео, папок та файлів анотацій; згруповані налаштування View.
- Відкриття наявних анотацій, окремі робочі JSON для відео з різних шляхів, явний вибір місця експорту через Save Annotations.
- Завантаження відео за HTTPS/S3 presigned-посиланням із паралельними з’єднаннями, прогресом, повторними спробами та скасуванням.
- Підтримка ZIP, TAR і TAR.GZ з одним MP4/MKV; після розпакування зберігається лише відео.
- Завантаження працює в модальному вікні. Фоновий режим із одночасною розміткою вимкнено; згортання додатку не перериває завантаження.
- Поле `active_work_seconds` у JSON: приблизний загальний час активної роботи над відео, накопичення між відкриттями та автозбереження. На паузі лічильник зупиняється після 60 секунд без дій; неактивний/згорнутий додаток не враховується.
- Виправлення роботи VLC з декодуванням H.264 та зупинки відтворення на межі інтервалу.

## Сумісність

- Схема анотацій залишається `1.0`; `active_work_seconds` — додаткове поле, відсутнє значення у старих JSON означає нуль.
- Історія останніх файлів зберігається між запусками; відновлення всього Playlist не передбачено.
- Потрібен системний VLC/libVLC. Інструкція встановлення входить до релізного архіву.
- Рефакторинг контролера заплановано окремо в `BACKLOG.md` (ARCH-001).
